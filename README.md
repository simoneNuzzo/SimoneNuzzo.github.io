# Simone Nuzzo — DJ & Event Services

Sito pubblico: https://simonenuzzo.github.io

Questa cartella contiene il sito statico pronto per GitHub Pages: HTML, CSS, JavaScript e fotografie. Il configuratore calcola pacchetto e optional e prepara il riepilogo da inviare su WhatsApp.

## Pubblicazione

GitHub Pages pubblica il branch `main`, cartella `/` (root). Il file `.nojekyll` permette di servire le risorse della cartella `_next`.

## Aggiornamenti

I file JavaScript e CSS in `_next/static` sono generati dalla compilazione del progetto. Aggiornare insieme HTML e risorse generate quando si pubblica una nuova versione. Le fotografie sono nella cartella `images`.
